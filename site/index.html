Process streams with patchbay

Use Patchbay to combine built-in forms into a processor tailored to your streams, with a few lines of configuration. Stateful forms keep values between messages for moving averages, deduplication and threshold alerts. Browse all available forms.

patchbay.edn
(on "sensors.*"
  (-> payload-float
      (round 1)
      (squelch)
      (publish! (subject-append "stable"))))

Three ways to
run monoblok

Project README

Before your cluster

Use monoblok as a front door. Condition incoming readings before they reach your cluster. Forward selected subjects to NATS.

Alongside your cluster

Subscribe to existing subjects in NATS, process the messages with monoblok and have it publish the results back to your cluster.

On its own

monoblok is a lightweight broker with processing built in. Connect your NATS clients directly to monoblok.

Written in C with libuv

monoblok runs its core processing on one thread, with rules and cached values held in memory. It builds on Linux and macOS.

Releases include binaries for Linux (x64 and ARM64) and macOS on Apple Silicon, plus Docker images for Linux x64 and ARM64.

2–18 million messages a second

Saved benchmark runs reach peaks across this range for simple publish and fan-out workloads on a 2-core ARM VPS, an 8-core x86_64 VPS and an Apple Silicon M4 Mac mini.

These results show efficient message handling, though throughput alone cannot capture NATS’ decade-plus of production maturity. Test your own workload to confirm capacity and latency.

NATS native, not a replacement

monoblok is designed to complement NATS. It works with self-hosted clusters and Synadia Cloud.

Export processed messages, import live subjects or replay JetStream history through patchbay. Explore NATS integration.

Install

Download a release binary, use the script below or run the Docker image.

macOS or Linux
$ curl -fsSL https://raw.githubusercontent.com/lexvicacom/monoblok/main/scripts/start.sh | bash

Or run with Docker

$ docker run --rm -p 14222:14222 ghcr.io/lexvicacom/monoblok:latest --port 14222
Installation guideDownload v0.4.3
Binaries require system OpenSSL 3:
  • Ubuntu 24.04 / Debian 13: sudo apt-get install libssl3t64
  • Ubuntu 22.04 / Debian 12: sudo apt-get install libssl3
  • RHEL 9: sudo yum install openssl-libs
  • macOS: brew install openssl@3

For ESP32: tinyblok runs Patchbay Lite, a subset of patchbay for ESP32 boards.
