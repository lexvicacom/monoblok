Process streams
with patchbay

Patchbay rules round, filter and transform messages as they arrive. Operators can keep state between messages, for averages, deduplication and threshold alerts.

patchbay.ednEDN / S-expressions
(on "sensors.*"
  (-> payload-float
      (round 1)
      (squelch)
      (publish! (subject-append "stable"))))

Project README

At the front door

Condition incoming readings before they reach your cluster. Forward just the subjects you need.

Alongside your cluster

Subscribe to existing subjects, process the messages and publish the results back to your cluster.

On its own

A lightweight broker with processing built in. Connect your NATS clients directly to monoblok.

Tiny and fast

Written in C with libuv, monoblok builds on Linux and macOS. It aims to be simple, lightweight and fast, even on entry level and shared hardware.

Easy to install as a single binary for Linux (x64 or ARM64) and macOS on Apple Silicon, or as a pre-built Docker image for Linux x64 and ARM64.

2–18 million messages a second

Saved benchmark runs reach peaks across this range for simple publish and fan-out workloads on a 2-core ARM VPS, an 8-core x86_64 VPS and an Apple Silicon M4 Mac mini.

These are directional samples and trends. Real-world capacity depends on your hardware, workload and processing rules.

Install

A single binary with no complex install.

macOS or Linux
$ curl -fsSL https://raw.githubusercontent.com/lexvicacom/monoblok/main/scripts/start.sh | bash

Or run with Docker

$ docker run --rm -p 14222:14222 ghcr.io/lexvicacom/monoblok:latest --port 14222
